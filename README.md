# 🎬 Movie Management System

A backend-based Movie Management System developed using **Python and MySQL**.

This project provides a structured system to manage users, movies, and reviews with database integration.

## 🚀 Features

- 👤 User Management
  - Add users
  - View users
  - Update user details
  - Delete users

- 🎬 Movie Management
  - Add movies
  - View movies
  - Update movie details
  - Delete movies

- ⭐ Review Management
  - Add reviews
  - View reviews
  - Update reviews
  - Delete reviews

- 🗄️ MySQL Database Integration
- 🔗 Relationships between Users, Movies, and Reviews
- 🧩 Modular project structure
- ⚠️ Exception handling
- 🔄 CRUD operations

## 🛠️ Technologies Used

- **Python**
- **MySQL**
- **MySQL Connector for Python**
- **Object-Oriented Programming (OOP)**
- **CRUD Operations**
